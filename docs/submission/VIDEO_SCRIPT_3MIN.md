## Checklist & Lệnh `ffmpeg` Chuẩn hóa trước khi Nộp

1. **Kiểm tra thời lượng & chuẩn MP4 (bắt buộc `< 180 giây`):**
   ```bash
   ffprobe -v error -show_entries format=duration,size:stream=codec_name,width,height -of default=noprint_wrappers=1 duong-dan-video-tho.mp4
   ```
2. **Cắt gọn về tối đa 165 giây & nén chuẩn H.264/AAC phát mượt mọi máy:**
   ```bash
   mkdir -p submission && ffmpeg -i duong-dan-video-tho.mp4 -t 165 -c:v libx264 -preset medium -crf 22 -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart submission/04-MoMo-TrustLoop-Demo.mp4
   ```
