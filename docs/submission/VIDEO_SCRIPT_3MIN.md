## Checklist & Lệnh `ffmpeg` Chuẩn hóa trước khi Nộp

1. **Chuẩn bị trước khi bấm Record (OBS):**
   - Chạy `POST https://momo-trustloop.vercel.app/api/demo/reset?session=momo-video` (hoặc bấm **Reset Dữ liệu Demo** trên `/` với `?session=momo-video`).
   - Phóng to chữ trình duyệt vừa đọc (`100%` hoặc `110%`), ẩn thanh bookmark thừa.
2. **Kiểm tra thời lượng & chuẩn MP4 (bắt buộc `< 180 giây`):**
   ```bash
   ffprobe -v error -show_entries format=duration,size -show_entries stream=codec_name,width,height -of default=noprint_wrappers=1 duong-dan-video-tho.mp4
   ```
3. **Nếu cần cắt gọn về 165 giây & nén chuẩn H.264/AAC dễ phát mọi máy:**
   ```bash
   ffmpeg -i duong-dan-video-tho.mp4 -t 165 -c:v libx264 -preset medium -crf 22 -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart submission/04-MoMo-TrustLoop-Demo.mp4
   ```
